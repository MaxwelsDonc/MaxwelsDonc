I study how to **evaluate intelligent systems when no ground truth exists**. Using metamorphic testing as the principal tool, I design verifiable and attributable metrics for oracle-less scenarios — from a completeness theory for testing deep-learning operators, to meta-evaluation of LLM reasoning reliability (LGMT), to validity assessment of neuron coverage metrics.

My current work focuses on **using evaluation signals to train models**. Since November 2026 I have been at [TensorWorld](https://www.tensorworld.com), setting up its evaluation system from the ground up. At ByteDance, I designed agent evaluation frameworks and built SenWorld, a digital-twin simulation that generates oracle-labeled evaluation data at scale.
